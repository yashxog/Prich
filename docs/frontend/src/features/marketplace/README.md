# Marketplace workspaces

The authenticated creator and brand dashboard routes now render role-specific marketplace workspaces.

Creators can browse open X and LinkedIn campaigns, submit an original post URL, review brand feedback, maintain role-specific social handles, and see Prich-derived submission, approval, and approved-reward totals.

Brands can create campaigns, review their commissioned posts, approve or reject each submission with feedback, maintain separate brand social handles, and see received, pending, and approved post totals.

The interfaces follow `DESIGN.md`: neutral editorial surfaces, one dominant action per form, persistent labels, keyboard-visible focus, status text paired with color, and responsive stacked layouts. The analytics connection note explicitly distinguishes unavailable external social metrics from live Prich campaign data.
